# Progress Interior Designs — Premium Website Redesign

## Direction
Build a completely new editorial, architecture-led website using near-black, ivory, white, and restrained amber accents. Use Manrope for display typography and Inter for body copy, with sharp geometry, generous whitespace, thin rules, and cinematic renovation photography sourced from optimized remote image links.

## Pages and navigation
- Create a polished shared header, mobile full-screen menu, persistent conversion actions, and a dark editorial footer.
- Build the primary homepage experience with the requested hero, statistics, company introduction, asymmetric service presentation, featured before/after project, benefits, masonry project gallery, process timeline, testimonials, emergency callout, FAQ, and estimate form.
- Add dedicated About, Services, Projects, Reviews, and Contact pages so every navigation item is a real, shareable destination with unique search metadata.

## Interactions
- Transparent-to-solid compact header on scroll.
- Restrained reveal animations, staggered typography, image masks, hover zooms, moving arrows, and animated statistics with reduced-motion support.
- Interactive before/after comparison, accessible FAQ accordion, full-screen mobile navigation, and a validated estimate form confirmation state.
- Sticky mobile “Call Now” and “Free Estimate” actions.

## Technical details
- Use reusable React/TypeScript sections and the existing component system.
- Keep all colors, typography, shadows, and motion values in semantic Tailwind v4 tokens.
- Use responsive image sizing, lazy loading below the fold, semantic landmarks, one H1 per page, descriptive alt text, keyboard-visible controls, and route-specific title/description/Open Graph metadata.
- Verify the completed pages at desktop and mobile sizes, checking menus, accordions, comparison control, navigation, and form behavior.
